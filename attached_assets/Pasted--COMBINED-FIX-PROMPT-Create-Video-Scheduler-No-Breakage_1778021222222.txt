**Fix:**
- Video generation API call mein `duration` parameter bhejo.
- `POST /api/video/generate` body mein add karo:
  ```json
  {
    "duration": "<selectedDuration>",
    "maxLengthSeconds": <selectedDuration === "short" ? 60 : 600>
  }
```

· Backend router (src/server/routers/video.ts) mein maxLengthSeconds ko FFmpeg -t argument mein convert karo.
· Agar Long select hai to script length automatically 300+ words ho; warning dikhao agar kam hai.
